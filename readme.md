# Система категорий и товаров

## Описание

Этот проект реализует базовую модель данных для работы с товарами и категориями. Включает два основных класса:

Product — описание отдельного товара;

Category — категория товаров с автоматическим подсчётом статистики.

## Структура проекта
project/
├── models.py          # Основные классы (Product, Category)
└── test_models.py     # Тесты с использованием pytest

Классы и их свойства
Product
Свойства экземпляра:

name (str) — название товара;

description (str) — описание товара;

price (float) — цена;

quantity (int) — количество в наличии.

Category
Свойства экземпляра:

name (str) — название категории;

description (str) — описание категории;

products (list[Product]) — список товаров в категории (по умолчанию — пустой список).

Атрибуты класса (общие для всех экземпляров):

total_categories (int) — общее количество созданных категорий;

total_products (int) — общее количество товаров во всех категориях.

Особенности:

Счётчики total_categories и total_products обновляются автоматически при создании нового объекта Category.

При создании категории с списком товаров счётчик total_products увеличивается на длину этого списка.

# Установка и запуск

1. Установите зависимости:

bash
pip install pytest

2. Разместите файлы:

models.py — классы;

test_models.py — тесты.

3. Запустите тесты:

bash
pytest -v
Флаг -v включает подробный вывод.

## Примеры использования
python
from models import Product, Category

# Создаём товары
p1 = Product("Смартфон", "Android", 29999.0, 5)
p2 = Product("Планшет", "iOS", 39999.0, 3)

# Создаём категорию с товарами
cat = Category("Мобильные устройства", "Смартфоны и планшеты", [p1, p2])

# Проверяем счётчики
print(Category.total_categories)  # 1
print(Category.total_products)     # 2

## Тестирование

Тесты проверяют:

корректность инициализации объектов Product и Category;

работу со счётчиками total_categories и total_products;

крайние случаи (цена/количество = 0, пустые категории).

Запускаемые тесты:

test_product_initialization — проверка создания товара;

test_category_initialization — проверка создания категории;

test_total_categories_counter — подсчёт категорий;

test_total_products_counter — подсчёт товаров;

и другие (см. test_models.py).
